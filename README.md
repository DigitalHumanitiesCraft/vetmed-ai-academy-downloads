# VetMed AI Academy downloads

Public download page and participant-package releases. The working repository and its Git history remain private.

GitHub Pages serves only docs/. Besides the download page it holds one prototype as a page, docs/equine-teaching-videos/, the standalone build of the teaching-video case with a draft explainer film that is not professionally reviewed. Editable case knowledge is distributed inside the ZIP release asset and is not rendered as website content.

The participant package contains local prototypes, declared example data, editable case knowledge and the German START.html entry. Internal work history is replaced with participant starting documents, machine-local paths are made portable, and third-party notices are retained. Build and publication are performed from the maintained working repository.

Original code uses MIT and original teaching material CC BY 4.0. Third-party material retains its own terms, included with that material.
